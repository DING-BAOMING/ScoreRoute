# Agent 执行规则

## 核心原则
1. **保持命令简单** - 不一次执行太多
2. **分开执行** - 每个步骤单独运行
3. **失败就重试** - 简单直接重试
4. **再失败换方式重试** - 换一种方式

## 写文件规则
- **只用 bash heredoc** - `cat > file << 'EOF'`
- **不用 write/read 工具** - 会堆栈溢出

## Git 规则
- **推送分支后不要切换回 main** - 避免本地分支被清理
- 推送后保持在推送的分支上工作

## Docker Build 规则
- Web build: `npm run build`
- Docker build: 成功后就继续，不要反复确认
- 失败就重试

## 执行流程
1. 执行命令
2. 等待结果
3. 成功就继续下一步
4. 失败就重试或换方式
