## 开发流程（重要！）

### 流程：生产环境开发 → 测试 → GitHub

这是经过验证适合用户情况的工作流程：

1. **直接修改生产环境代码** - 因为用户没有编程基础，完全依赖 AI
2. **测试验证** - 改完立即测试
3. **推送到 GitHub** - 代码备份

### 为什么这样？

| 传统方式 | 当前方式 | 原因 |
|---------|---------|------|
| 分支开发 | 直接生产环境 | 用户无法操作分支 |
| 合并后再部署 | 部署即测试 | 减少中间环节 |
| CI/CD 流程 | 手动推送 GitHub | 简化流程 |
