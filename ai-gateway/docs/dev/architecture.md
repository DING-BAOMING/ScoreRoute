# 系统架构

## 技术栈

- 后端: Go + Gin
- 前端: Vue3 + Element Plus
- 数据库: SQLite
- 部署: Docker

## 核心模块

### Proxy Handler
处理所有/v1/*请求，验证Token，路由分发。

### Dispatcher
根据评分选择最优模型，处理轮询逻辑。

### Scheduler
定时任务：自动重启用过期禁用项。

### Repository
数据库访问层，处理所有CRUD操作。

## 数据流

```
请求 → Proxy → Token验证 → Dispatcher → 评分选择 → 上游API
                                                      ↓
响应 ← Proxy ← Token/模型更新 ← 日志记录 ←
```

## 评分算法

```
Score = 成功率×0.10 + 延迟分×0.10 + 稳定性×0.10 
      + 用户评分×0.20 + 样本评分×0.30 + 成本评分×0.10 
      + 时间评分×0.10 + 奖励 + 惩罚
```

## 自动禁用规则

| 限制类型 | 禁用范围 | 自动重启用 |
|---------|---------|----------|
| Token速率限制 | 仅Token | ✅ |
| Token总Token限制 | 仅Token | ❌ |
| 模型速率限制 | 仅该模型 | ✅ |
| 渠道速率限制 | 仅该渠道 | ✅ |
