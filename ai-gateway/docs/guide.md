# 用户指南

## 功能概览

### 接入管理
管理AI渠道，支持OpenAI、NVIDIA、Minimax、Zhipu等多种Provider。

### 模型管理
添加、编辑、测试模型，查看模型评分。

### 接出管理
创建API Token，设置调用限制。

### 日志查看
查看API调用记录，分析使用情况。

## 渠道管理

### 添加渠道
1. 进入"接入管理"页面
2. 点击"添加渠道"
3. 填写API信息
4. 设置速率限制

### 速率限制说明
- `1500次/5小时` - 每5小时最多1500次调用
- `15000次/周` - 每周最多15000次调用

## 模型评分

系统根据7个因子自动计算模型评分：
- 成功率 (10%)
- 延迟分数 (10%)
- 稳定性 (10%)
- 用户评分 (20%)
- 样本评分 (30%)
- 成本评分 (10%)
- 时间评分 (10%)

奖励/惩罚机制会动态调整分数。

## 智能路由

使用`"model": "auto"`时，系统自动选择当前最高分模型。
