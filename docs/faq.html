常见问题

遇到问题？这里可能有答案

ScoreRoute 是什么？

ScoreRoute 是一个开源的AI网关项目，支持多模型路由、负载均衡、故障转移和智能评分功能。通过统一的接口接入多个AI模型，智能分发请求，提高系统可用性和性能。

支持哪些AI模型？

支持所有OpenAI兼容的API，包括GPT-4、GPT-3.5、Claude、Gemini、国产模型（通义千问、文心一言等）。只需配置相应的API Key即可使用。

如何部署？

支持多种部署方式：1) 使用 install.sh 一键安装（推荐）；2) Docker Compose；3) 手动编译。详见快速开始页面。

数据安全吗？

所有数据存储在本地SQLite数据库，不会上传到任何第三方服务。API密钥加密存储，开源透明可审计。详见安全与隐私页面。

开源免费吗？

是的，基于MIT协议开源，可以免费商用，无需付费。

需要什么配置？

最低配置：1核CPU、1GB内存、5GB磁盘空间。推荐配置：2核CPU、2GB内存、10GB磁盘空间。

如何更新版本？

拉取最新代码，重新构建Docker镜像：git pull && docker build -t scoreroute-app . && docker-compose up -d

如何获取帮助？

可以通过GitHub Issues提问，或加入飞书群联系开发者。
