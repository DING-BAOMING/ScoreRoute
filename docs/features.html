核心功能

强大的AI网关功能，让你的AI应用更稳定、更高效

多模型路由

支持GPT、Claude、Gemini、MiniMax等多种AI模型统一接入。通过智能路由算法，自动选择最优模型处理请求。

支持的模型类型：

  • 文本模型：GPT系列、GLM系列、MiniMax等
  • 视觉理解：GPT-4V、GLM-4V等
  • 图像生成：DALL-E、CogView等
  • 视频生成：CogVideoX等

负载均衡

自动分发请求到多个模型实例，提高系统吞吐量。支持连接池管理、请求队列、限流熔断。

支持的路由策略：

  • 随机（Random）
  • 轮询（Round Robin）
  • 加权（Weighted）
  • 最小延迟（Least Latency）

故障转移

模型失败时自动切换，保障服务连续性。支持重试机制、自动跳过不可用模型、健康检查。

SLA高达99.9%

轮询调度

按调用次数升序轮询，均匀分配负载。简单可靠的负载分配策略，适用于所有模型表现相近的场景。

在"模型管理"页面，点击"调度模式"按钮即可切换。

智能调度

根据综合评分选择最优模型，优先选择表现最好的。评分维度包括：

  • 样本评分 (25%) - 样本分析得出的评分
  • 成功率 (15%) - 成功请求占总请求的比例
  • 成本评分 (15%) - 免费模型90分，付费模型70分
  • 用户评分 (15%) - 用户对模型的1-100评分
  • 延迟分数 (10%) - 延迟越低分数越高
  • 稳定性 (10%) - 样本量越多评分越可靠
  • 时间评分 (10%) - 基于模型过期时间

模型评分

多维度量化模型表现，为路由决策提供数据支撑：

  • 成功率 (28%) - 成功请求占总请求的比例
  • 延迟分数 (21%) - 基于平均延迟计算
  • 稳定性 (21%) - 基于样本量计算
  • 用户评分 (15%) - 用户对模型的1-100评分
  • 样本分析 (15%) - Agent能力评估

样本分析

保存和分析API调用样本，特别适用于Agent场景下的模型评估。

样本保存规则：

  • 只保存响应Token数 ≥ 500 的请求
  • 每个模型只保存一个最新样本
  • 样本保存7天，到期自动删除
  • 异步保存，不影响API响应速度

分析机制：

  • 每2小时自动分析最多20个样本
  • 按剩余时间升序（即将过期优先）
  • 分析完成后自动删除样本
  • 分析失败自动重试最多3次

附加评分机制

智能调度的额外奖惩机制，实现模型轮转调用。

惩罚机制：

  • 当某个模型被调用时，所有模型都会被扣除一定分数
  • 每次调用 -5分惩罚
  • 防止过度使用单一模型

奖励机制：

  • 新模型加入时获得+5分奖励
  • 持续24小时
  • 基于时间的线性衰减

API Key管理

安全的Key存储与轮换，支持多个API密钥集中管理。

  • 加密存储、最小权限
  • 支持重新生成Key
  • Token Key仅显示一次
  • 可绑定特定格式和模型

Agent能力评估维度

工具调用 (30%)

是否正确识别并调用工具，参数是否正确

完整性 (25%)

是否完整回复用户请求，无遗漏

上下文理解 (20%)

是否正确理解对话上下文

错误处理 (15%)

错误处理和模糊请求处理能力

回复质量 (10%)

回复的清晰度和格式

渠道与模型管理

渠道管理

渠道是对接不同AI服务商的配置：

  • API地址 - AI服务商提供的API端点
  • API Key - 渠道的身份凭证
  • 格式 - OpenAI/Anthropic/Azure/Google/智谱Zhipu

可设置限制：

  • 总Token限制 - 渠道可用Token总数上限
  • API有效期 - 渠道API密钥的过期时间
  • 调用频率限制 - 次数/Token数（每分钟/小时/天/周/月/年）

模型管理

模型是具体可调用的AI模型，关联到渠道：

  • 每个模型必须属于一个渠道
  • 模型类型: Chat/Embedding/Image/Video
  • 支持批量添加模型
  • 可从API自动获取可用模型列表

可设置限制：

  • 总Token限制、模型有效期
  • 调用频率限制（次数/Token数）
  • 每Token费用、货币单位(CNY/USD)
  • 汇率设置（USD兑换CNY）
