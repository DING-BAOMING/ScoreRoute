快速开始

简单快捷，三步即可部署

首页 > 快速开始

登录凭证（本地部署）

  • 用户名: admin
  • 密码: 一键安装自动生成 / Docker部署请在.env中设置
  • 首次登录: 请立即修改默认密码！

方式一：一键安装（推荐）

自动检测端口，支持自定义端口

# 克隆项目
git clone https://github.com/DING-BAOMING/ScoreRoute.git
cd ScoreRoute/ai-gateway
# 运行安装脚本
./install.sh

# 安装过程中会：
# 1. 自动检测端口3000是否被占用
# 2. 如果被占用，提示输入其他端口
# 3. 自动生成随机管理员密码
# 4. 构建并启动Docker容器

# 默认端口: 3000
# 可自定义选择其他端口

方式二：Docker Compose

# 克隆项目
git clone https://github.com/DING-BAOMING/ScoreRoute.git
cd ScoreRoute/ai-gateway

# 复制配置
cp .env.example .env

# 编辑 .env 填入配置
nano .env

# 重要配置项：
# ADMIN_PASSWORD=your_secure_password
# JWT_SECRET=your_jwt_secret

# 修改端口（如需）
# 编辑 docker-compose.yml 中的端口映射：
# - "3000:3000" 改为如 "8080:3000"

# 启动
docker-compose up -d

# 查看状态
docker ps

# 查看日志
docker logs -f scoreroute-app

方式三：手动编译

# 环境要求
# - Go 1.23+
# - Node.js 20+
# - GCC (for CGO)

# 克隆项目
git clone https://github.com/DING-BAOMING/ScoreRoute.git
cd ScoreRoute/ai-gateway

# 配置
cp .env.example .env
nano .env

# 构建前端
cd web && npm install && npm run build && cd ..

# 构建后端
go build -o server ./cmd/server

# 运行
./server

配置说明

# .env 配置文件示例

# 服务端口
PORT=3000

# 数据库路径
DATABASE_PATH=./data/gateway.db

# 日志路径
LOG_PATH=./logs

# 管理员密码（请修改为强密码）
ADMIN_PASSWORD=your_secure_password_here

# JWT密钥（请使用随机字符串）
JWT_SECRET=your_jwt_secret_here

验证部署

# 检查容器状态
docker ps

# 访问管理界面
curl http://localhost:3000

# 查看日志
docker logs scoreroute-app --tail 50
