安全与隐私

本地优先，开源透明，你的数据你做主

本地数据存储

所有数据存储在本地SQLite数据库，不依赖第三方云服务。数据库文件保存在本地文件系统，完全可控。

API Key安全

API密钥加密存储，支持密钥轮换。遵循最小权限原则，确保密钥安全。

开源透明

基于MIT协议开源，代码公开可审计。无隐藏后门，无数据收集。

JWT认证

使用JWT进行用户认证，Token有过期时间。支持自定义过期时间。

请求日志

完整的请求日志记录，便于审计和问题排查。敏感信息脱敏处理。

安全建议

强密码

使用强密码作为管理员密码，包含大小写字母、数字和特殊字符。定期更换密码。

JWT密钥

使用随机生成的JWT密钥，不要使用默认值。在生产环境中定期轮换。

网络隔离

在生产环境中，将ScoreRoute部署在内网，并使用Nginx反向代理加HTTPS。

数据备份

定期备份数据库文件和配置文件。数据库位于 ./data/gateway.db。
