## 一、需求遗漏补充

### 1.1 遗漏的功能点
1. **登录凭证固定**：密码固定为 `dbm52100`
2. **模型获取功能**：需要从API（如NVIDIA）获取可用模型列表
3. **模型测试功能**：测试模型是否可用
4. **轮询状态持久化**：call_count需要在数据库持久化
5. **流式响应支持**：SSE/Streaming响应处理
6. **健康检查功能**：渠道可用性检测
7. **前端加载状态**：显示API调用状态
8. **Token计数同步**：轮询后计数器更新

### 1.2 逻辑漏洞补充

| 漏洞 | 描述 | 解决方案 |
|------|------|----------|
| 并发安全问题 | 多个请求同时读取+更新call_count | 使用数据库原子操作 UPDATE SET call_count = call_count + 1 |
| 流式响应日志 | Streaming响应无法预知token数量 | 使用启发式估算或分段记录 |
| 模型禁用处理 | 禁用模型时正在调用的请求 | 返回503 Service Unavailable |
| Key验证时序 | key可能在请求处理中被禁用 | 在请求开始时锁定key状态 |
| 日志轮转实现 | 需要配置logrotate | 提供docker-compose中的日志配置 |

## 二、技术方案（稳定性优先）

### 2.1 架构决策

| 组件 | 选择 | 理由 |
|------|------|------|
| 后端 | Go + Gin | OneAPI验证过的成熟方案 |
| 前端 | Vue3 + Element Plus | 中文友好，组件完善 |
| 数据库 | SQLite | 单用户场景足够，零运维 |
| 日志 | 文件 + logrotate | 轻量可靠 |
| 部署 | Docker Compose | 一键部署 |

### 2.2 核心数据结构

```sql
-- 渠道表（API接入）
CREATE TABLE channels (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    format TEXT NOT NULL,           -- openai, anthropic, etc
    type TEXT NOT NULL,             -- chat, embedding, etc
    base_url TEXT NOT NULL,
    api_key TEXT NOT NULL,
    enabled INTEGER DEFAULT 1,
    priority INTEGER DEFAULT 0,     -- 优先级（可选）
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 模型表
CREATE TABLE models (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    channel_id INTEGER NOT NULL,
    name TEXT NOT NULL,
    enabled INTEGER DEFAULT 1,
    call_count INTEGER DEFAULT 0,   -- 轮询计数器
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (channel_id) REFERENCES channels(id)
);

-- 令牌表（接出API）
CREATE TABLE tokens (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    key TEXT UNIQUE NOT NULL,       -- sk-xxxx
    name TEXT NOT NULL,
    format TEXT NOT NULL,
    type TEXT NOT NULL,
    model_name TEXT NOT NULL,
    enabled INTEGER DEFAULT 1,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 调用日志表
CREATE TABLE call_logs (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    token_name TEXT,                -- 接出API名
    channel_name TEXT,              -- 接入渠道名
    model_name TEXT,
    latency_ms INTEGER,
    token_used INTEGER DEFAULT 0,
    status INTEGER,
    error TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 系统配置
CREATE TABLE config (
    key TEXT PRIMARY KEY,
    value TEXT
);
```
